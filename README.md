## Proje hakkında

Kotlin öğrenirken yaptığım ilk çalışmalardan biri. Oyunun temel mantığını
uygular: kart çekersin, elindeki toplam ekranda görünür, 21'i geçersen
kaybedersin.

## Özellikler

| | |
|---|---|
| **Kart çek / bırak** | İki butonla oynanır |
| **Toplam göstergesi** | Elindeki kartların toplamı ekranda yazar |
| **21 kuralı** | Toplam 21'i geçerse oyun kaybedilir ve ekranda bildirilir |

Uygulama bilinçli olarak sade: animasyon ya da özel tasarım içermez, yalnız
oyun mantığına odaklanır.
